# HandNote 0.9.1

Fix for pen tablets on the desktop. Notes, writing on the iPad and recognition are unchanged.

- **Space + pen drag pans the page.** With a pen tablet (Wacom, Huion, XP-Pen…), holding Space and
  dragging with the pen moved nothing and drew a stroke instead; only the mouse could pan this way.
  The pen now pans like the mouse, on notebook pages and on imported documents. Without Space the
  pen writes as before.
- **Pen side button as middle button pans.** If the tablet driver maps a pen button to the middle
  mouse button, holding it and dragging pans the page, so the keyboard is not needed.
- A pan that ends outside the page area now ends cleanly.
- The plugin description in the directory now mentions document annotation.

---

修复电脑上的数位板：按住空格用笔拖动，以前会写字而不是移动页面（只有鼠标可以），现在笔和鼠标一样可以移动页面，导入的文档也一样；不按空格时照常书写。在数位板驱动里把笔的侧键设成「中键」后，按住侧键拖动也能移动页面。笔记、iPad 上的书写和识别都没有变化。
