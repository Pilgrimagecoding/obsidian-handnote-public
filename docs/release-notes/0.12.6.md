# HandNote 0.12.6

## Links between notes

- Write `[[Sketch.handnote]]` in a text box to link to another HandNote file; ordinary Markdown notes can be linked too.
- Links use a distinct colour and underline. Tap a link to open the destination.
- Type `[[` to choose a file, or use the **Insert link to a note** command. HandNote targets keep the `.handnote` extension.
- Links are published to Obsidian's graph/link index. Renaming a target updates links in HandNote notes when **Automatically update internal links** is enabled. The backlinks pane may not list links originating in `.handnote` files.

## Phone layout

- Compact toolbars and subbars scroll horizontally while retaining usable touch targets.
- Popovers fit the screen, with safe-area spacing for narrow displays.
- Canvas density is capped at 2× on phone-sized layouts to reduce redraw memory; tablet layouts retain their existing density.

## Grouped Markdown annotations

- Group members share an anchor chosen from the part touching the text, so editing between a circle and its arrow does not pull them apart.
- Undo and redo restore the group's position and line anchor after a lasso move.
- Nearby strokes written in quick succession can group automatically. Disable this in settings, or select a group with the lasso and ungroup it.

Existing `.handnote` and Markdown annotation files remain compatible; no migration is required. The global Chinese/English language setting and all 0.12.5 features remain available.

## 中文

- **笔记链接**：文本框支持 `[[草图.handnote]]`，输入 `[[` 可选择目标文件，也可用「插入笔记链接」命令。链接以独立颜色和下划线显示，轻点即可打开；接入关系图／链接索引，目标文件改名后按 Obsidian 的自动更新链接设置修改链接。反向链接面板可能不显示来自 `.handnote` 的链接。
- **手机界面**：工具栏和子工具栏适配窄屏并可横向滑动，保留可点按的按钮尺寸，弹层限制在屏幕内并考虑安全区；手机布局的画布像素倍率最高为 2 倍，以降低内存占用，平板保留原有倍率。
- **Markdown 笔迹成组**：组内笔迹共用文字锚点；修复套索移动后撤销／重做的位置恢复。连续写下、位置相近的笔迹可自动成组，设置中可关闭，也可以套索选中后取消组合。
- **已有文件兼容**：无需迁移，保留全局中英文切换和此前版本的功能。
