# HandNote 0.12.4 — sharper Markdown annotations and full-note exports

## 中文

- **iPad 放大更清晰**：改善 Markdown 正文、手写笔迹和嵌入预览放大后的显示；嵌入的 HandNote 笔迹、形状和文字使用 SVG 预览。导入文档中的扫描图仍保持原图细节。
- **Markdown 与批注一起导出**：支持 PDF、PNG、SVG，包含原排版正文和手写内容。修复导出文字间距变化、多余空白尾页及各页尺寸不一致。长文 PDF 为多页，PNG／SVG 分段打包为 ZIP；Markdown SVG 按高清合成图封装。
- **笔记导出升级**：PNG／SVG／PDF 菜单可选择当前页或整本笔记；支持保存到本机或仓库，显示导出完成、取消或系统分享状态。提高导出清晰度，PDF 手写笔迹使用矢量路径，修复较大笔记导出的内存预算误报。
- **批注自动打开**：在编辑视图打开已有笔迹、文本框或图片等批注的 Markdown 时，自动进入批注模式；普通笔记照常打开。同一标签页手动退出后保持退出，换开其他笔记后再回来才重新自动进入。
- **工具栏更简洁**：更多菜单固定在三个点下方并右对齐。移除“完成”按钮，通过“更多 → 退出 HandNote 批注”或标题栏 HandNote 图标退出。
- **批注文件更贴近正文**：批注保存在对应 MD 旁边，例如 `Note.md.handnote`，跟随笔记／文件夹改名。旧批注兼容读取，打开时自动处理旧目录中的批注，Markdown 正文保持原样。
- **单文件导入**：新导入文档将原始文件和批注封装进一个 `.handnote`，保留原始文档字节，不再额外创建 `HandNote imports` 副本。改善大 PDF 的存储、打开及移动端兼容性；已有外部底稿和旧笔记继续兼容。
- **中英文全局设置**：可在插件设置中选择中文或英文，菜单和设置随之统一切换；导入、导出等操作使用不同图标，诊断工具收纳到独立区域。
- **页面导航更直接**：侧栏使用带数量的“所有页面／书签”筛选。

升级提示：新导入的单文件笔记需要 0.12.4 或兼容后续版本打开，请同步更新各设备。原有笔记无需手动迁移；旧文档底稿不会自动删除。Markdown 组合导出按原布局分段，接缝可能切在文字行或图片中间；SVG 合成图和扫描底图不会因放大获得额外细节。同步服务可能仍传输整个封装文件。

## English

- **Sharper iPad Markdown zoom:** improve enlarged Markdown text, handwriting and embed previews. HandNote embeds use SVG for ink, shapes and text; imported scans retain their original image detail.
- **Export Markdown with its annotations** to PDF, PNG or SVG. Preserve native text shaping, remove empty trailing sheets and keep sheet sizes consistent. Long notes produce a multi-page PDF or an ordered PNG/SVG ZIP; Markdown SVG wraps a high-resolution composite image.
- **Expanded notebook export:** choose the current page or whole notebook, then save locally or to the vault. Clear save/cancel/share feedback, higher-resolution output, vector handwriting in PDF and improved export memory handling.
- **Open annotations automatically** for Markdown notes that already contain ink or objects, in editing view. Manually leaving annotation mode keeps it off in that tab until another note is opened there.
- **Simpler toolbar:** the More menu opens directly below its button. Exit through More → Exit HandNote annotations or the title-bar HandNote icon; the Done button has been removed.
- **Colocated annotation files:** keep `Note.md.handnote` beside `Note.md`, follow note/folder renames and retain compatibility with older annotation locations without modifying the Markdown text.
- **Single-file document imports:** preserve the original document bytes and annotations in one `.handnote`, avoiding an extra imports-folder copy. Improve large-PDF storage, opening and mobile compatibility while retaining older external-source notes.
- **Global Chinese/English interface selection**, distinct action icons, grouped diagnostics and All pages / Bookmarks filters with counts.

Update all devices to 0.12.4 or a compatible later version before opening newly packaged imports. Existing notes remain compatible and old source documents are not automatically deleted. Composite exports use layout-preserving tiles, so a boundary can cross a text line or image; SVG composites and scans remain raster. Sync services may still transfer the complete package.

Install/update HandNote through Obsidian Settings → Community plugins → Check for updates.
