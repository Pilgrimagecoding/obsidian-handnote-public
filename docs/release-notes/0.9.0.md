# HandNote 0.9.0

Annotate documents by hand, and a finger long-press menu for pasting.

**Import documents to annotate** — the **Import document…** command (also in the editor menu), or
right-click a PDF, Word, PowerPoint or Excel file in the file list → **Annotate in HandNote**. Each page of the document becomes a
HandNote page of the same size; you write on it like on any other page.

- **PDF** — rendered on demand by the PDF engine that ships with Obsidian.
- **Word (.docx and older .doc)** — laid out once into fixed pages: headings, paragraphs and their
  styles, lists, tables (column widths, merged cells, borders), pictures, landscape sections. Page
  breaks are close to Word's but not identical. Headers / footers, footnotes, text boxes, charts and
  equations are not shown; the import says which ones a file has. For .doc, pictures and list
  numbering are not shown yet.
- **PowerPoint (.pptx)** — one page per slide: background, master and layout shapes, placeholders,
  bullets, preset shapes, pictures (cropped, rotated), groups and tables. Animations, charts,
  SmartArt, video and shadow effects are not shown.
- **Excel (.xlsx)** — printed onto A4 pages like OneNote (landscape when a sheet is wide), cells at
  their real size from the top-left corner, with headings, gridlines, fills, borders, merged cells,
  fonts, wrapping, number formats and pictures. **Formulas show the result saved in the file;
  HandNote does not recalculate.** Hidden rows, columns and sheets are skipped; charts and
  conditional formatting are not shown.
- Pick several files at once on the iPad: they are imported in the order you chose them.
- Older .ppt / .xls, Pages / Keynote / Numbers, OpenDocument and password-protected files are
  refused with the reason and what to do (for example "save as .pptx or PDF").

**Your files stay yours.** The original document is kept as a separate file in your vault (folder
`HandNote imports`, configurable in Settings → Imported documents) and is never modified; importing
the same file again does not copy it twice. The note stores only a reference and your ink. Word,
PowerPoint and Excel files get a small layout file beside them (`<name>.handnote-layout.json`, or
`.json.gz` when large) so every device shows exactly the same pages — make sure your sync tool syncs
it; if it is missing HandNote lays the file out again. Renamed or moved originals are followed; if
one is deleted, your annotations stay. Macros never run, remote images and links are not loaded,
and nothing is uploaded: everything happens on your device.

**Finger long-press menu.** Hold a finger on the page for about half a second: Paste (what you
copied in HandNote), Paste from clipboard (text or a picture from another app), Text box here,
Insert image here. The Apple Pencil is not affected. On desktop, right-click opens the same menu
and Ctrl+V pastes. iPadOS shows its own "Paste" confirmation when a note reads the clipboard.

**Compatibility.** Notes that contain imported pages are saved as format 6; HandNote 0.8.x opens
them read-only. Update HandNote on every device that edits them. Notes without imported pages are
saved exactly as before. On-device text recognition and model packs are unchanged; this edition
still has no on-device math recognition.

`main.js` is about 6.2 MB (the recognition runtime is built in). Obsidian Sync's Standard plan does
not sync files over 5 MB — install HandNote on each device from Community plugins in that case.

**导入文档批注**：「导入文档…」命令（编辑器菜单里也有），或在文件列表里对 PDF / Word / PowerPoint / Excel 文件右键 →「在 HandNote 中批注」。文档的每一页变成同样大小的 HandNote 页面，可以直接书写。支持 PDF（用 Obsidian 自带的 PDF 引擎渲染）、Word（.docx 和旧版 .doc）、PowerPoint（.pptx）、Excel（.xlsx，像 OneNote 一样印在 A4 纸上；公式显示文件中保存的结果，不重新计算）。iPad 上可以一次选多个文件，按选择顺序导入。不支持的格式会说明原因和办法。原文件单独保存在仓库的 `HandNote imports` 文件夹（可在设置中修改），不会被修改，也不会重复保存；Word / PowerPoint / Excel 旁边会有一个排版文件，保证各设备页面一致，请让同步工具同步它。不运行宏，不加载远程内容，不上传任何文件。

**手指长按菜单**：手指长按页面约半秒，可以粘贴、从剪贴板粘贴、添加文本框、插入图片；Apple Pencil 不受影响。桌面版右键打开同一菜单，Ctrl+V 粘贴。

**兼容性**：含导入页面的笔记以格式 6 保存，0.8.x 只能只读打开，请在所有编辑这些笔记的设备上更新。其他笔记格式不变。本机文字识别不变；此版本仍不含本机公式识别。`main.js` 约 6.2 MB，Obsidian Sync 标准版不同步超过 5 MB 的文件，请在每台设备上安装插件。
