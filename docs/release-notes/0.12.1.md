# HandNote 0.12.1

**Ink on Markdown**: write by hand directly on your ordinary Markdown notes, in Obsidian's own
editor, with the same tools as in a HandNote note. Your `.md` file is never changed: the ink is saved
in a separate annotation file. Also: the shape pen recognises gently bent lines as curves.

Notes made with earlier versions open as before.

## Ink on Markdown

- **Turn it on** with the HandNote pen icon at the top right of a Markdown tab, or with the command
  *Turn HandNote annotation on / off for the current Markdown note*. The HandNote toolbar appears
  above the note. Tap the icon again, or **Done** on the toolbar, to turn it off. A note in reading
  view switches to the editing view.
- **The note stays an editable note.** With a pen, eraser, lasso, laser or the hand tool selected,
  the Apple Pencil only writes: it does not move the cursor, select text or start Scribble. **Tap the
  text with a finger** to type right there; when the keyboard closes or the Pencil touches the
  screen again, the Pencil writes again. Links, checkboxes and fold arrows react to a finger tap as
  usual.
- **Tools, as in notes:** fountain pen, pencil, highlighter and the shape pen (real shapes and
  connectors; draw a "V" at the end of a line to add an arrow head); eraser; the HandNote lasso (move, resize, rotate, copy, cut, delete, recolour, group: ink, text
  boxes, images and shapes); text boxes (tap anywhere, also in the margin); images (stored in the
  annotation file, large images are scaled down first); shapes; laser pointer; undo / redo, also
  with a two-finger / three-finger tap.
- **Gestures, as in notes:** one finger pans with inertia, also sideways into the margin (up to half
  a screen, or as far as your outermost annotation); two fingers zoom from 50 % to 800 %, and the
  text is laid out again at the new size, so it stays sharp and editable. Tap the zoom percentage
  to go back to 100 %. On a computer, the mouse or a pen tablet draws, and Ctrl/⌘ + wheel or a
  trackpad pinch zooms.
- **Annotations follow the text.** Every stroke, text box, image and shape belongs to the line next
  to it: add or delete lines above it and it moves with that line. **A highlighter laid on words
  follows those words**, also when text is inserted before them in the same paragraph or they wrap
  to the next row (the highlight then splits into one piece per row). When the note is changed
  elsewhere, annotations find their line again by line number and text; **an annotation whose line
  cannot be found stays where it was and is never deleted.**
- **Saving:** the ink is saved automatically in `HandNote annotations/<path of the note>.handnote`,
  an ordinary, visible folder that syncs like the rest of your vault. Nothing is written into the
  Markdown file. The same safety as notes: a version check before writing (a file changed elsewhere
  is kept as a copy), a recovery journal, and a damaged annotation file opens read-only. Renaming or
  moving a note moves its annotations; deleting a note keeps them. A second tab on the same note
  shows the ink read-only, so the two cannot overwrite each other.
- **⋯ menu:** save now, clear all annotations (ink, text boxes, images and shapes; one undo brings
  everything back), exit, and *Copy diagnostics* (page structure and settings only, no note text).

## Shape pen

- **A gently bent line is a curve** (in notes too). A line that bends smoothly to one side by about
  4.5 % of its length is now a curve; before, it had to bend by more than 10 %. Hand tremor, which
  wobbles to both sides, still gives a straight line. In a simulated test, all 108 casual straight
  lines (bent up to 3 %) stayed straight, and 87 % of smooth 6–9 % bends became curves (before: 5 of
  108). Handwriting is not mistaken for shapes more often than before.

## Known limitations of Ink on Markdown

- The ink is shown only in the editing view, not in reading view and not where the note is
  embedded in another note.
- No PNG / PDF export of an annotated Markdown note yet.
- The lasso has no *Convert* and *AI* buttons on Markdown notes.
- Ink follows its line, not the shape of the sentence: words added in the middle of a circled
  sentence do not stretch the circle. Moving or resizing a highlight with the lasso makes it ordinary
  ink again. Inside callouts and tables, highlights follow the block's line, not single words.
- In Live Preview, the line with the cursor shows its Markdown source (for example `**bold**`, a
  formula or a table). While that line is wider or taller, the ink beside it is briefly out of place;
  it returns when the cursor leaves the line.
- On another device with a different font, font size or window width, ink still follows its line,
  but its horizontal position can differ.
- Opening an annotation file from `HandNote annotations/` directly shows the ink without the text.

## Compatibility

- An annotation file is an ordinary `.handnote` file; the file format version is unchanged. It has a
  few new optional fields: the annotated note (`annotates`), the line a stroke or object belongs to
  (`a`, `anchor`) and the words a highlight covers (`sp`). HandNote 0.11.1 and older open these files
  as ordinary notes and drop the new fields when they save.
- The Markdown notes themselves are never written by this feature.

## 中文说明

- **在 Markdown 笔记上直接手写批注**：点 Markdown 标签页右上角的 HandNote 笔尖图标，或用命令「在当前 Markdown 笔记上打开 / 关闭 HandNote 批注」。笔记上方出现 HandNote 工具栏；再点一次图标或点「完成」关闭。笔记在阅读视图时会切到编辑视图。
- **笔记仍然可以编辑**：选笔、橡皮、套索、激光笔或抓手时，Apple Pencil 只写字，不会移动光标、选中文字或触发随手写（Scribble）。**用手指点一下正文**就能在那里打字；键盘收起或 Pencil 再碰屏幕时，Pencil 继续写笔迹。手指点链接、复选框、折叠箭头和平时一样。
- **工具和 HandNote 笔记一样**：钢笔、铅笔、荧光笔和形状笔（真正的形状和连接线，在线的末端画「V」加箭头）；橡皮擦；HandNote 套索（移动、缩放、旋转、复制、剪切、删除、改色、编组，笔迹、文本框、图片、形状都能套）；文本框（点哪里就在哪里，也可以放在页边）；图片（存进批注文件，太大的会先缩小）；形状；激光笔；撤销 / 重做，也可以双指 / 三指轻点。
- **手势和笔记一样**：单指拖动带惯性，也可以左右拖到页边（最多半屏，或一直拖到最外侧的批注旁边）；双指缩放 50%–800%，正文按新大小重新排版，保持清晰、可以编辑。点缩放比例回到 100%。电脑上鼠标或数位板写字，Ctrl/⌘ + 滚轮或触控板捏合缩放。
- **批注跟着文字走**：每一笔、每个文本框、图片、形状都属于旁边那一行，上面加行、删行时跟着这一行移动。**荧光笔划过的字，荧光笔就跟着这几个字**：同一段前面加字、被标的字折到下一排时也跟过去（折成两排时分成两段）。笔记在别处被修改后，按行号和文字重新找到它的行；**找不到时留在原处，绝不会被删除。**
- **保存**：自动保存在 `HandNote annotations/<笔记路径>.handnote`，是普通的可见文件夹，和仓库其他内容一样同步。Markdown 文件里不写入任何东西。和笔记一样有写入前的版本检查（被别处改过就另存副本）、恢复日志，批注文件损坏时只读打开。笔记改名、移动时批注跟着走；删除笔记时批注保留。同一篇笔记在第二个标签页里只读显示，避免互相覆盖。
- **「⋯」菜单**：立即保存、清除所有批注（笔迹、文本框、图片、形状一起清，撤销一次全部回来）、退出批注、复制诊断信息（只含页面结构和设置，不含笔记文字）。
- **形状笔：稍微弯一点的线也认成曲线**（笔记里同样生效）：平滑地往一边弯出约 4.5% 就算曲线，以前要超过 10%。手抖造成的两侧来回摆仍然认成直线。模拟测试：108 条弯曲 3% 以内的随手直线全部仍是直线，弯出 6–9% 的平滑弯线 87% 认成曲线（以前 108 条里只有 5 条）；手写文字被误认成形状的比例没有变化。
- **已知限制**：只在编辑视图显示笔迹，阅读视图和嵌入到其他笔记里时看不到；还不能把批注过的 Markdown 笔记导出为 PNG / PDF；Markdown 笔记里的套索没有「转换」和「AI」按钮；笔迹跟着行走，不随句子变形（在被圈的句子中间加字，圈不会变长）；用套索移动或缩放荧光笔后，它变回普通笔迹；标注框（callout）和表格里的荧光笔按整块的行跟随；实时预览中光标所在行显示源码，变宽或变高时旁边的笔迹会暂时错开，光标移开就恢复；字体、字号、窗口宽度不同的设备上，笔迹仍跟着行，但横向位置可能有偏差；直接打开 `HandNote annotations/` 里的文件只能看到笔迹，看不到正文。
- **兼容性**：批注文件是普通的 `.handnote` 文件，文件格式版本不变，只多了几个可选字段（`annotates`、`a`、`anchor`、`sp`）。0.11.1 及更早版本会把它当作普通笔记打开，保存时丢掉这些字段。这个功能从不写入 Markdown 笔记本身。
