# HandNote 0.12.3

- **Large PDF imports.** The PDF file size limit rises from **200 MiB to 512 MiB**. HandNote hashes the file in chunks and releases PDF inspection resources before saving a new copy to reduce peak memory use. A 400 MiB test PDF was successfully imported and opened on iPad. Actual capacity depends on the device and PDF contents.
- **Long PDFs.** HandNote imports the full document up to **10,000 pages**. Above that limit it asks you to split the PDF. Previous versions could silently stop at 2,000 pages.
- **Clearer errors.** HandNote checks the header of a picked file before reading the full file. An all-zero header now gets an explanation about possible placeholders, damage, or incomplete downloads.

Update through **Settings → Community plugins → Check for updates**.

## 中文

- **大 PDF 导入。** PDF 上限从 **200 MiB 提升到 512 MiB**。分块校验，并在保存新副本前释放 PDF 解析资源，降低导入时的内存峰值。已在 iPad 上成功导入并打开一份 **400 MiB** 测试 PDF。实际可导入大小取决于设备和 PDF 内容。
- **长 PDF 完整导入。** 最多完整导入 **10,000 页**。超过上限会提示拆分，修复了旧版在 2,000 页处静默截断的问题。
- **更清楚的文件提示。** 从设备导入时先检查文件头。遇到全零开头会提示可能是占位文件、损坏或下载不完整。

在 Obsidian 的 **设置 → 第三方插件 → 检查更新** 中升级。
