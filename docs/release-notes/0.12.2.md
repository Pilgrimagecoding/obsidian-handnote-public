# HandNote 0.12.2

- **Drawing tablet cursor.** Choose **Small dot** or **Crosshair** under **Settings → HandNote → Writing → Writing cursor**. Crosshair remains the default. Your choice takes effect immediately and is saved.
- **Write while scrolling on iPad.** When a HandNote page is still coasting after a swipe, touching it with Apple Pencil stops the page and starts the stroke at the point of contact.
- **Recover from interrupted input.** If a pen or mouse release is missed, the next contact can start a new stroke. A cancelled drag now clears the dragging state.

Update through **Settings → Community plugins → Check for updates**.

## 中文

- **数位板光标。** 在 **设置 → HandNote → 书写 → 书写光标** 中选择「小圆点」或「十字」。默认使用十字，切换即时生效并保存。
- **iPad 落笔即停。** 手指滑动后，即使页面仍在惯性滚动，Apple Pencil 落笔时页面也会立刻停住，笔迹从落点开始。
- **输入中断后恢复。** 系统漏发抬笔或鼠标释放事件时，下一次接触可以开始新笔划。拖动取消时会退出拖动状态。

在 Obsidian 的 **设置 → 第三方插件 → 检查更新** 中更新。
