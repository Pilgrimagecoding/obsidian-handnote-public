# HandNote 0.8.1

Maintenance release after the first community-directory scan. No change to writing, notes or
recognition results.

- On-device recognition runs only in a Web Worker; the in-page fallback, which injected a module
  script, is removed (no device we test on ever needed it).
- The bundled Chinese stroke data no longer carries a blanket `eslint-disable` comment.
- The interface language follows Obsidian's `getLanguage()`.
- Releases carry build-provenance attestations; checksums are listed in the release notes instead of
  an extra file.
- README / FAQ: `main.js` is about 5.9 MB (built-in runtime), above the 5 MB file limit of Obsidian
  Sync's Standard plan — install HandNote on each device in that case.
