# 在 Markdown 笔记上手写批注

[← 中文文档首页](README.md)

从 0.12.1 起，HandNote 可以直接在普通的 `.md` 笔记上手写。不用新建 HandNote 笔记，也不用把 Markdown
转成别的格式：笔迹写在 Obsidian 自己的编辑器上，笔记照常可以编辑，**`.md` 文件本身一个字都不会被改动**。

## 1. 打开和关闭

- 打开任意 Markdown 笔记，点标签页右上角的 **HandNote 笔尖图标**（打开后图标高亮）。
- 也可以用命令「在当前 Markdown 笔记上打开 / 关闭 HandNote 批注」，可以在「设置 → 快捷键」里给它设快捷键。
- 笔记上方出现和 HandNote 笔记一样的工具栏。
- 关闭：再点一次图标，或点工具栏右边的「完成」。
- 笔记在阅读视图时，会自动切到编辑视图；笔迹只在编辑视图里显示。

## 2. Pencil 和手指的分工

选钢笔、铅笔、荧光笔、形状笔、橡皮、套索、激光笔或抓手时：

| 操作 | 结果 |
|---|---|
| Apple Pencil 在正文上写 | 只写笔迹：不会移动光标、不会选中文字，也不会触发 iPad 的随手写（Scribble） |
| 手指点一下正文 | 在点的位置出现光标和键盘，可以直接打字 |
| 键盘收起，或 Pencil 再碰屏幕 | 回到书写状态，Pencil 继续写笔迹 |
| 手指点链接、复选框、折叠箭头 | 和平时一样打开链接、勾选、折叠 |
| 单指拖动 | 平移页面，带惯性；也可以左右拖到页边空白（最多半屏，或一直拖到最外侧的批注旁边） |
| 双指捏合 | 缩放 50%–800%；松手后正文按新大小重新排版，保持清晰，也照常可以编辑 |
| 双指轻点 / 三指轻点 | 撤销 / 重做（和 HandNote 笔记一样，可以在设置里关掉） |

点工具栏上的缩放比例，回到 100%。

电脑上：选笔时鼠标或数位板写字，Ctrl/⌘ + 滚轮或触控板捏合缩放。

## 3. 工具

和 HandNote 笔记里是同一套：

- **笔**：钢笔、铅笔、荧光笔、形状笔。形状笔画出来的是真正的形状和连接线；在线的末端画一个「V」会加上箭头。
- **橡皮**：和笔记里一样的几种模式，也可以只擦荧光笔。
- **套索**：笔迹、文本框、图片、形状都能套选；可以移动、缩放、旋转、复制、剪切、删除、改颜色、编组。Markdown 笔记里的套索没有「转换」和「AI」按钮。
- **文本框**：选「文字」工具，点哪里就在哪里出现文本框，也可以放在页边。这是批注层上的文本框，不会写进 `.md`。要改正文本身，用手指点一下正文打字即可。
- **图片**：从相册或文件中选择。图片存进批注文件，不会在仓库里另外生成附件；太大的图片会先缩小。
- **形状**：矩形、椭圆、三角形、直线、箭头等，可以改线型、颜色和填充。
- **激光笔**：演示用，不保存。
- **「⋯」菜单**：立即保存、清除所有批注（笔迹、文本框、图片、形状一起清，撤销一次就全部回来）、退出批注、复制诊断信息（只含页面结构和设置，不含笔记文字）。

## 4. 批注跟着文字走

- 每一笔、每个文本框、图片、形状都属于旁边的那一行。在上面加几行、删几行，它们跟着这一行一起移动。
- **荧光笔划过的字，荧光笔就跟着这几个字**：同一段前面加了字、被标的字被挤到别的位置或折到下一排，荧光笔都会跟过去；折成两排时分成两段。划在字上、字下面（像下划线）都可以。
- 关闭批注后在别处改了笔记（另一台设备、另一个软件），下次打开时按「行号 + 这一行的文字」重新找到它的行。
- **找不到所在的行时，批注留在原处，绝不会被删除。**被荧光笔标的字整个删掉时，荧光笔留在原处，变成普通笔迹。

## 5. 保存在哪里

- 批注自动保存在 `HandNote annotations/<笔记路径>.handnote`。例如 `课程/机器学习/第 3 讲.md` 的批注在
  `HandNote annotations/课程/机器学习/第 3 讲.handnote`。
- 这是普通的可见文件夹，和仓库里的其他文件一样同步（同步插件通常会跳过以点开头的隐藏文件夹，所以没有用隐藏文件夹）。
- 和 HandNote 笔记一样安全：写入前检查版本，文件在别处被改过就另存一份副本，不覆盖；有恢复日志；批注文件损坏时只读显示，不会被改写。
- 笔记改名、移动时，批注文件跟着移动；删除笔记时，批注文件保留，不会自动删除。
- 同一篇笔记在两个标签页里同时打开批注时，第二个只读显示，避免两边互相覆盖。

## 6. 已知限制

- 笔迹只在编辑视图显示，阅读视图里、把这篇笔记嵌入到别的笔记里时看不到。
- 还不能把批注过的 Markdown 笔记导出为 PNG / PDF。
- 笔迹跟着「行」走，不随句子变形：在被圈住的句子中间加字，圈不会变长。
- 用套索移动或缩放一条贴在字上的荧光笔后，它离开文字，变回普通笔迹（只改颜色或编组不会）。
- 标注框（callout）和表格在 Obsidian 里是整块显示的，里面的荧光笔按整块所在的行跟随，不能跟到单个字。
- 实时预览里，光标所在的那一行会显示源码（比如 `**粗体**`、公式或表格源码）。这一行变宽或变高时，旁边的笔迹会暂时对不齐，光标移开就恢复。
- 在字体、字号或窗口宽度不同的设备上，笔迹仍然跟着行走，但横向位置可能有偏差。
- 直接打开 `HandNote annotations/` 里的批注文件，只能看到笔迹，看不到正文。
