# 已知限制与兼容性

[← 中文文档首页](README.md)

以下内容以公开版 HandNote 0.9.1 为准。

## 平台

| 平台 | 状态 |
|---|---|
| iPad（Obsidian iPadOS 版）+ Apple Pencil | 主要目标平台：压感、防误触、手指平移和缩放、双指撤销 |
| Windows / macOS / Linux | 鼠标、数位板、触屏、快捷键 |
| iPhone / Android | 没有使用桌面专用接口，理论上可用，但未测试；手机布局没有优化 |

- 需要 Obsidian 1.11.4 或更高版本。
- iPad / iPhone 上的本机识别需要 iPadOS / iOS 16.4 或更高版本。

## 识别

- **没有本机公式识别。** 用 LaTeX 输入，或用你自己的 MyScript 密钥。
- 识别模型针对一般手写训练：字特别小、笔迹特殊、一行里混写多种文字时，准确率会下降。不确定的结果会给出候选，确认前保留原笔迹。
- 内置离线中文识别只适合工整中文，连笔、英文、数字效果差。

## 文档导入

- Word / PowerPoint / Excel 由 HandNote 自己排版，不使用 Microsoft Office：分页、字体、换行可能和 Office 略有不同。
- 不显示：图表、SmartArt、动画、页眉页脚、脚注、文本框、Word 中的公式、条件格式。
- Excel 公式显示文件里保存的结果，不会重新计算。
- 旧版 .ppt / .xls 需要先另存为 .pptx / .xlsx 或 PDF；.doc 的图片和列表编号暂不显示。
- 单个文件最大 200 MB。
- PDF 页面不能选中文字、点击链接，导出的 PNG 是页面图片，不是带批注的 PDF。

## 版本兼容

- 用新版本 HandNote 创建的笔记，在旧版本里只能只读打开。请在所有编辑同一批笔记的设备上使用相同版本。
- 含导入页面的笔记使用文件格式 6，HandNote 0.8.x 只能只读打开。
- 损坏的文件（例如同步中断）会以只读方式打开，并可以「保存恢复的副本」，原文件不会被改写。

## 体积与同步

- `main.js` 约 6.2 MB，因为识别运行库内置在插件里。Obsidian Sync 标准版不同步超过 5 MB 的文件，请在每台设备上安装插件。
- 识别模型保存在每台设备的应用存储中，不随仓库同步，每台设备需要各自下载。
- 卸载插件不会自动删除已下载的模型，请先在「本地识别」里删除。

## 隐私

- 没有遥测、统计和账号，插件没有自己的服务器。
- 所有联网行为（模型下载、可选的 MyScript 和 AI 服务）都列在 [PRIVACY.md](../../PRIVACY.md)。
